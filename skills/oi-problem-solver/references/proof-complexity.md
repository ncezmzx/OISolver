# 正确性证明与复杂度核算

## 证明方法按对象选择

- 递归／DP：良基参数、全部基例、转移可靠性与完备性、依赖顺序、答案提取。
- 循环／数据结构：初始化、每条分支保持、退出推出后置条件；终止量有下界且严格下降。
- 贪心：候选与平局、交换／割／stays-ahead 安全性、交换后可行且不劣、残余子问题同型。
- 图算法：原问题到图模型的双向保真、权值／方向／重边前提、路径／割／流等证书。
- 数学命题：定义域、量词、除数／逆元／单调方向；必要性和充分性单独关闭。
- 均摊／随机：见下，不用一次实验代替证明。

证明算法不等于证明代码。补作的证明应标为“审查者补证”，不能说原说明已经给出。

## 半形式化推导链

关键 `PROVED`／`CONDITIONAL` 结论必须拆为 `proof_chain`：

- `premises`：逐项给 id、statement 与 `explicit/source-confirmed/inference/assumption/unknown` 来源等级；
- `edge_cases`：逐项给 id、最小／空／重复／退化情形及 `covered/excluded-by-premise/unresolved` 处理；
- `steps`：按顺序给原子 statement、五态 status、role、justification、premise／edge-case 引用和只指向前序步骤的 `depends_on`；
- `conclusion`：必须指向链内最后关闭的结论步骤。`PROVED` 链不能依赖 `CONDITIONAL/TESTED_ONLY/UNRESOLVED/REFUTED` 步骤。

机械探针至少检查：等价命题是否同时有 necessity/sufficiency；贪心是否有 exchange/cut/stays-ahead；DP 是否有 base/transition/extraction 与退化边界；均摊是否有 potential/charging；随机化是否定义 probability-space。探针命中只说明证明义务未关闭，不自动说明最终命题为假。

`assumption/unknown` 前提或 `CONDITIONAL` 推理步骤会生成定向反例建议：保持已关闭的早期前提，否定一个缺失前提，并搜索最小合法输入。建议本身是待执行计划，不是已找到反例。

## 复杂度账本

固定规模变量、字长模型、多测总和和实际实现。逐阶段登记：预处理、排序、递归、每次更新／查询、重建／清空、输出；最后求和。区分最坏、均摊、期望和实测。

### 分治与 CDQ

列 `层数 / 每层活跃总规模 / 每项非递归成本 / 额外排序或结构操作`。

- 等半分治每层总记录量通常为 `O(n)`，但不代表每层成本必为 `O(n)`。
- 每节点对 k 项重新排序 `Θ(k log k)` 时，第 d 层为 `Θ(n(log n-d))`，总计 `Θ(n log² n)`。
- 保持有序并线性归并，排序／归并总成本可为 `O(n log n)`。
- CDQ 每层 `O(n)` 次 Fenwick 操作且单次 `O(log U)`，递归深度 `O(log n)`，对应 `O(n log n log U)`；若另有每节点排序必须单列，不能把两种实现的优点拼接。
- 清全值域数组要按递归节点数计；逐点撤销则按真实更新次数计。严格维度必须处理平局分组。

### 数据结构与树

- 每次操作 × 操作总数；动态开点按访问路径和根／版本数计节点，不按值域全部建树，也不忽略持久化复制。
- 路径复制点改通常每版本 `O(log U)` 新节点；查询若会 push，也可能破坏只读版本。
- 树形 DP 对每个孩子重算其余孩子可在星形树达到 `Θ(Σdeg²)`；关联运算满足条件时才用前后缀降为 `Θ(Σdeg)`。
- HLD 跳 `O(log n)` 条链、每链结构查询 `O(log n)` 通常相乘为 `O(log² n)`。
- 递归栈按最坏原树／搜索深度计，不能借用外层分治深度。

### 均摊和期望

均摊必须给聚合收费对象、记账或势能。势能法写出 `实际成本 + ΔΦ`、初始势能及终态下界；不能把均摊 O(1) 写成单次最坏 O(1)。

随机化写清概率空间、随机源、输入是否适应种子、独立性及保证是期望／高概率／错误率。期望时间不等于有限最坏上界；固定公开哈希参数不能套随机种子碰撞界。

## 内存与可行性

统计同时存活的输入、图、容器 capacity、节点池、历史版本、临时副本、递归栈和分配器开销。必要时按目标 ABI 的 `sizeof` 估 MiB，并把理论上界与实测峰值分开。最后结合题目时空限制、常数、缓存和 STL 开销判断；数据范围缺失则只给条件化结论。
